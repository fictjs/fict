# Fict Library Publishing Example

This example is a minimal third-party hook library that uses `@fictjs/vite-plugin` library mode.

`pnpm build` compiles the library, emits `dist/*.fict.meta.json`, and keeps `package.json#fict.exports` in sync with the public entries.

The important pieces are:

- `vite.config.ts` uses `fict({ library: true })`.
- `package.json#exports` declares the public JavaScript entrypoints.
- `package.json#fict.exports` is generated by the plugin and points consumers at the emitted metadata files.
- `files: ["dist"]` ensures `npm pack` includes the generated metadata.

This example commits the generated `fict.exports` block so repeated builds stay clean. Removing that block and running `pnpm build` will regenerate it.

Remove `"private": true` and set a real package name/version before publishing this as an npm package.
